## 下载源码后直接运行（Windows）

1. 下载**包含本次修复的分支**源码 ZIP，完整解压到可写目录，例如 `D:\Shuban`。支持中文和空格路径；不要在压缩软件内直接打开启动文件。
2. 双击根目录 [一键启动.cmd](一键启动.cmd)。**首次需要联网**：脚本自动下载项目专用 Python、Node.js，校验 SHA256，安装锁定依赖并构建网页。可能需要数分钟，请保留窗口等待完成。
3. 浏览器就绪后自动打开。优先使用 `http://127.0.0.1:18080/`；被占用或被 Windows 预留时会自动选择可用端口并记住，以实际打开的网址为准。
4. 此后仍双击同一文件。环境、依赖和源码未变时复用本地结果；演示功能无需联网。远端模型调用需要网络和本地配置；本机模型服务需另行准备，不由此启动器安装。

**无需预先安装 Python、Node.js、npm 或数据库，不需要管理员权限，不修改系统 PATH。** 下载的环境位于被忽略的 `.runtime/`，前端依赖和构建结果分别在 `frontend/node_modules`、`frontend/dist`。这就是普通源码文件夹的自动初始化，无需另取便携包。

自动初始化面向 **Windows 10/11 Intel/AMD 64 位**。Windows ARM、Mac/Linux 未提供此自动安装脚本；学校的应用白名单、PowerShell禁用或网络限制仍需管理员处理。首次完全离线且没有缓存时不能安装环境。

常用参数，在源码根目录执行：

```powershell
# 只准备环境，不启动后端、不打开页面
./start.ps1 -SetupOnly
# 自动准备并运行，不打开浏览器
./start.ps1 -NoBrowser
# 指定端口（被占用时明确报错，不关闭其他进程）
./start.ps1 -Port 18081
```

每个文件夹的安装和启动分别有锁，避免重复双击造成同时安装或重复进程。关闭网页不会结束后端；重启电脑会结束。需要停止时，可在任务管理器按启动输出的后端 PID 核对并结束该项目进程，勿批量结束所有 Python。

## 首次失败怎么排查

- **下载失败/校验失败**：按窗口中的文件和网址检查网络，再次双击重试。已通过校验的下载会复用，未校验的内容不会执行。运行时源为 python.org、nodejs.org；pip源为 files.pythonhosted.org，包安装还需访问 PyPI 和锁文件列出的 npm 下载地址。
- **前端依赖被占用**：先停止这个文件夹正在运行的 Vite/构建进程，再次启动；安装器会尽可能提前检查，不主动关闭其他程序。
- **后端失败**：查看 `backend/server.err.log`；启动失败不等于数据已删除。端口冲突可去掉 `-Port` 自动选择。
- **空间不足**：保持项目盘有足够空间（建议至少2GB）。安装临时文件与npm/pip缓存放在项目 `.runtime/`，避免只依赖C盘空间。
- **旧启动器仍提示手动npm ci**：说明仍在使用旧源码。请重新下载最新main源码并完整解压；旧ZIP不会自动更新。

详细机制、已验证范围和限制见 [源码启动说明](docs/source-startup.md)。

## C 教师闭环验收

教师建档/登录→班级管理创建班级与学生→班级卡片“布置作业”→“从题库选题”按章选择、跨章组合与调整顺序→返回完善要求/日期，保存草稿或发布→学生首次改密后提交→教师人工反馈→学生修改→教师复核新版→归档。

题库不再占用侧栏，但新建、编辑、归档题目及私有参考答案仍在选题窗口内。按上下册第1–12章顺序展示有题目的分组，自定义章节排在后面，不再先选章节再选题；这里内置的是分类和选题入口，不是自动导入教材习题。目录依据见[架构与教材来源](docs/architecture.md)。选题只追加标题/题干，不覆盖已填要求，不带入参考答案；每批最多30题，总题干不超过3000字符。

作业表单不再要求选择“所属章节”，截止日期保留。首次空白题干选同章题时自动使用该章，跨章或与现有不同章节内容混合时使用“综合练习”；手写新作业默认综合练习。未重新选题的旧草稿保留原有非空topic。

班级卡片“查看作业”进入本班草稿/已发布/已归档列表；“班级成员”进入独立成员与进度页，可返回班级管理。未分班草稿可从“全部作业与草稿”继续编辑。教师侧栏仅保留教学概览、班级管理、教学助手和账号设置。

空草稿可保存但不可发布；发布班级必须属于教师且至少有一位有效学生。发布时固定收件人，后加学生不自动收到旧作业；需要时复制并重新发布。已发布班级/题干锁定，可延期或复制新草稿。参考答案不进入学生响应。修改作答产生新版本，旧反馈不沿用；退班学生保留原作业只读历史，停用账号不能登录，归档班级下作业不可提交/批改。

班级进度、概览和 CSV 使用实际成员/收件快照、提交及人工反馈。应交是发布收件人数量，不因后来退班/停用而缩小；未交为应交减已交。默认总览排除草稿、归档作业及归档班级，不推断掌握度。验收使用合成账号，不能写成真实师生试用。

成员行仅显示“设置”，点击后改姓名、重置密码、移出/恢复或停用/启用账号，原权限不变。左上角“批量操作”开启勾选，支持移出/恢复成员；全选仅针对当前可见列表，切换筛选/页面或刷新会清空勾选。确认弹窗显示名单与人数，逐人执行，首个请求失败时停止后续操作并提示核实刷新结果；成功操作不回滚，超时不自动重试。批量仅改变本班成员身份，不停用账号、不影响其他班级，不是批量导入。

CSV仅导出当前班级的搜索和成员状态筛选结果，采用UTF-8 BOM、引号转义和公式前缀防护；包含学生账号、姓名与进度，请妥善保管。下载/Excel打开仍需在标准浏览器补验，不能仅依据生成测试认定落盘成功。

在“教学助手”聊天顶部点击“对话记录”，可查看全部历史、搜索问题或章节、筛选已收藏和刷新；点击记录回到当前聊天查看原回复。桌面“最近的问题 → 全部记录”也可进入，小屏保留顶部入口。打开/关闭记录不会清空未发送内容，“新问题”才清空。新的提问仍独立处理，不自动带入历史上下文。学生原有学习记录/收藏导航保留，共享智能体页面也可使用此入口。

## B 智能体模式与边界

可将 `.env.example` 复制为根目录 `.env`，填写自己的配置。真实密钥只保存在本地，禁止提交。

- `AGENT_MODE=auto`：配置 `MODEL_BASE_URL`、`MODEL_API_KEY`、`MODEL_NAME` 后使用模型，否则演示；`demo` 明确禁止模型调用，含识别接口。`live` 缺配置时仍如实回到演示。
- 兼容 Chat Completions；`MODEL_BASE_URL` 可为服务的 `/v1` 地址或完整 `/chat/completions`。可选 `MODEL_VISION_NAME` 指定视觉模型。
- 问答页面和历史按每条回复显示模型/演示来源，展示检索引用与待复核状态。调用失败时明确降级，提示随回复保存。原有历史继续兼容读取。
- 模型网络超时默认30秒，配置限制为1–60秒；前端AI请求等待90秒。异常不会自动重试，接收失败应先查历史，避免重复保存。
- 本地检索是内置课程片段的BM25，资料仍待课程复核；不是已完成的课程上传、向量库或pgvector。
- 当前检索仅7个知识点、2个主题，与教师题库12章分类独立。9/21合成测试发现积分/级数错误建议导数主题，识别请求和返回格式校验亦有缺口；`model.ready`只表示配置齐全，不证明服务可用。完整发现与后续实测条件见测试报告。
- 步骤/诊断中的关键词只用于生成候选与自检提示，不能凭关键词确定学生答错或推断知识掌握。规则步骤反馈统一为`unclear`。
- B的流式问答、识别、诊断和步骤反馈保留后端接口。当前智能体页已有拍照搜题入口，识别文本可编辑并在确认后回填提问框；须配置可用视觉模型，真机与真实视觉质量仍待验收。步骤反馈和诊断页面入口仍待完成；建议知识点目前只是主题标签，识别结果不能直接作为已核实题干。
- 长期记忆、推荐练习、评价、总结与资源检索（第二阶段），以及分层提示、图形批注、数学工具、语音服务适配、准确性评测与教师纠错（第三阶段）已在本地实现；异步任务、自动评分、正式身份体系、PostgreSQL与公网部署尚未完成。本地多账号/多班级不等于这些能力已经具备；师生试用及效果验证仍为暂定。
- 第三阶段新增接口见 docs/contracts/README.md。未配置语音服务时转写返回 503 并提供浏览器原生方案，不返回编造文本；图形批注与数学工具的坐标、求导结果由本地工具算出（零第三方依赖），模型只写讲解文字；教师纠错以追加补偿证据修正判断与状态，原始学习证据保留。

## 数据与更新

默认数据保存在 `backend/demo.db`（文件名为兼容保留，不表示内容都是演示数据），源码模式遵循 `.env` / `DATABASE_URL`。教师工作空间迁移目标为 schema v3，仅支持 SQLite。旧库先备份后事务升级，为各教师建立历史教学班并保留旧可见范围、作答和反馈；空库不植入演示数据。详见 [迁移与恢复](migrations/README.md)。
