## 怎么用

1. 双击 `shuban-ui-v1.html`
2. 左侧栏五个板块：**Own / Agent / Class / More / Setting**
3. 右上角按钮切换**浅色 / 深色**
4. **Setting → 视觉设计**：切换三种风格、主题色、标记色；**Setting → 页面与顺序**：用 ↑↓ 按钮调整侧栏顺序
5. 也支持 URL 参数，便于分享和截图：

```
?view=own|agent|class|more|setting
&style=lite|standard|pro      （精简 / 常规 / 繁杂）
&theme=dark|light
&accent=%235b4bb8             （主题色）
&mark=%237ee787               （标记色）
```

## 设计取向

- **一套设计语言 × 三档密度**，不是三套独立风格：精简 / 常规 / 繁杂之间只切换 CSS 变量与少数布局规则，落地成本低。这一点与 C 稿的「三套独立设计语言选一套」是评审时的核心分歧点。
- 取题是**数学教室的文具**：坐标纸网格、钢笔墨蓝、荧光笔划重点。全站只有一个高饱和色（标记色），用在"AI 划重点 / 当前选中 / 关键数字"上。
- **Own 的数学图案是算出来的**：JS 按参数方程实时绘制（2D 玫瑰线 / 双纽线 / 心形线 / 摆线，3D 螺旋线 / 环面纽结 / 球面螺线，4D 四维双旋转），每次进入随机一条，支持拖拽转视角。不使用任何图片素材。
