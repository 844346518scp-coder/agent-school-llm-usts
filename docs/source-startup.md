# 源码下载与自动启动

最后更新：2026-09-21。源码自动初始化仍为默认方案。0.2 B/C集成已发布；v0.3账号/班级功能已以8799cd0上传原分支`codex/c-local-teaching`，未合main。本地`codex/teacher-workspace`的9/20至21教师界面增量尚未上传。旧ZIP不会自动更新，远端main也不包含本轮本地改动；其拍照/原型增量未合入本工作区。

## 用户要求与实现

本次目标是下载完整源码文件夹后即可双击启动；之前的独立便携包不能替代这一要求。新版一键启动.cmd仍调用start.ps1，默认执行bootstrap.ps1，自动建立项目私有环境并构建网页，再调用platform/portable.py的--source模式启动后端与同源静态页面。

首次需联网；缓存完整且源码/依赖未变时不再下载安装。无需全局Python、Node或管理员权限；不改变系统PATH。进程内补全系统PowerShell模块路径，兼容被其他Shell影响的PSModulePath。

## 下载与缓存

固定使用Python3.13.13 Windows x64嵌入式ZIP、Node22.23.2 Windows x64 ZIP、pip26.2.1 wheel；下载URL与SHA256均固定在bootstrap.ps1，来源为Python/Node官网及PyPI文件服务。先下载.partial文件，哈希匹配后才解压/使用。版本调整须更新哈希并重新验收；不动态执行网上安装脚本。

.runtime下保存下载、解释器、npm/pip缓存及临时文件。Python依赖按requirements.lock.txt全部版本核验安装到独立哈希目录；嵌入式_pth忽略系统PYTHONPATH/用户包。前端npm ci遵循锁文件及integrity，当前锁文件有npmmirror/CDN下载地址，慢网下需等待。前端源码/配置指纹变化才重新构建，变化失败则不启动旧构建。失败可再次双击重试。

已忽略的环境/缓存/构建目录是生成物，不属于新增维护源码目录；不要提交它们。真实.env、数据库、日志继续被忽略。

## 启动与数据

默认单个FastAPI进程提供页面/API，优先18080；自动模式遇其他程序占用或Windows保留端口会换端口并记住，显式-Port不可用报错。目录锁防并发，instance_id核对目录，health要求agent_version=0.2.0、teaching_version=0.3.0、schema_version=3；检测到同目录旧后端会报错要求停止，不能自动换端口绕过旧服务以并行写同一数据库。

源码模式保留.env及DATABASE_URL，空值使用backend/demo.db；便携模式固定包内库。v0.3新增schema v3迁移及历史班级，升级前停止所有同库写入者并先验副本，详见[迁移说明](../migrations/README.md)。自动安装不覆盖.env和数据库。空库默认显示教师建档；仅显式SHUBAN_SEED_DEMO=true且用户表为空时植入演示数据，重启不会补回被改变的账号/作业。

-SetupOnly仅准备环境；-NoBrowser启动但不打开网页；-Dev使用原先的.venv + 系统Node开发方式，保留8000/5173热更新。出现依赖文件被开发服务占用时需先停止本项目开发服务，不自动终止其他程序。

## 当前能力与下一步边界

自动启动只解决环境准备和交付一致性。本轮账号与多班级来自应用实现，不是自动安装带来的能力；正式认证、PostgreSQL、真实模型效果和公网安全保障仍未完成。已有公开演示账号不会因升级而自动变安全。

远端main后续增加的拍照Vue入口只记录了类型检查和生产构建，尚未做真机、后端或真实视觉模型联调；独立视频原型也没有对应后端接口。源码自动启动能把仓库文件构建出来，不等于这些能力已经通过运行验收。继续开发前先按AGENTS.md对齐本地与远端基线。
