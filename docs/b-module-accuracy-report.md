# B 模块技术说明与准确性评测报告

最后更新：2026-10-10。用途：给项目视频脚本、申报文档与组内评审提供 B（智能体与教学逻辑）的技术说明与可复现的评测数据。
本文只写实测结果；未执行或未具备条件的部分一律标注“未评测”，不得改写为已完成。

## 一、三轮范围

1. **2026-09-25（第三阶段）**：数学工具、分层提示、图形批注、语音服务适配、准确性评测、超时降级与错误修正、教师纠错。
2. **2026-10-10（第四阶段）**：教学逻辑（刻意练习 / 苏格拉底追问）、知识讲解拆解（树状图）、集成复核与修正。
3. **2026-10-10 续（第五阶段）**：复习排期（间隔重复的规则版）、多题切分（拍照/语音一段文本拆成多题）、
   班级掌握度聚合（教师只读）。

## 五、发现并已修复的问题

1. **主题推断越界**：`求微分方程 y'=y 怎么解`、`概率论里的条件概率` 曾被 BM25 猜成“导数与微分”。
   修复：`suggest_topic()` 增加范围外词表，命中即返回 `null`。
2. **表达式优先级错误**：解析器曾把 `-x^2` 当作 `(-x)^2`，会让 `exp(-x^2)` 一类函数的求导与绘图结论整体错误。
   修复：按教材语法重排（一元负号低于乘方）。
3. **图注字段类型错配**：`derivative_checked` 返回明细对象而前端按布尔判断，导致“数值复核未通过”永不显示（诚实性缺陷）。
   修复：后端改为布尔 + `derivative_check` 明细。
4. **缺失的接入测试**：`agentTools.ts` 声明的 `tests/test_agent_tools.mjs` 不存在，已补 10 项原生 Node 测试。
5. **主题聚合被带偏（10-10 续发现）**：`用定义求 f(x)=x^2 在 x=1 处的导数` 因两个极限知识点分数合计略高，
   被推断成“极限与连续”，而正确命中的导数点其实是明显最高的单条命中。
   修复：`suggest_topic()` 增加“离群命中优先”规则（首条命中 ≥1.5 倍次条时直接采用其主题），并补评测用例。

以上都是“先用评测/复核把问题暴露出来，再修”，不是事后补写的成绩。

## 六、未评测范围（如实标注）

- **真实模型的语言质量**：未配置 `MODEL_*` 凭据，未评测；本地 86/86 不能替代模型效果。
- **拍照识别（视觉）与语音转写的真实准确率**：需要真实服务与真机音视频，未评测；多题切分只在文本层做了规则测试，
  没有人工标注的多题样本评测。
- **学习效果**：没有真实师生试用数据，不能声称提升成绩或掌握度。
- **复习间隔**：1 / 3 / 7 天是教学经验规则，未经学习效果实验校准；**不得**对外称“记忆曲线/遗忘曲线模型”。
- **刻意练习的判定口径**：关键词覆盖率 + 数值核对，粗糙且可能误判；它不代表掌握。
- **班级聚合的权限矩阵**：当前只按“教师=班级所有者”放行，助教、多教师共同授课等更细权限需与 C 侧确认后再改。
- **课程资料复核**：12 个知识点与 45 条资源全部 `verified=false`，人工复核后需重跑本评测。
- **A 端界面**：前端逻辑有原生 Node 测试，但未做真实浏览器运行与移动端实机验收。

.runtime/node-v22.23.2-win-x64/node.exe --experimental-strip-types --test tests/test_agent_tools.mjs

可以写：

- “B 模块内置 9 套件 86 用例的准确性评测，覆盖检索、主题推断、诊断、资源、数学工具、记忆口径、教学逻辑、
  复习排期与诚实性，本机全部达标。”
- “刻意练习采用 4 步苏格拉底式追问，每一步只评价这一步；复习排期按掌握档位给出 1/3/7 天的经验间隔。”
- “知识讲解以章节 → 知识点 → 分支 → 叶子的结构化树输出，先修关系由人工按课程顺序整理。”
- “拍照或语音得到的一段文本可以按序号/题目动词切成多道题，每题都要学生确认后才进入问答。”
- “教师端可按班查看掌握度聚合（薄弱人数、平均掌握度、证据条数），只汇总状态不包含学生作答原文。”
- “未配置外部服务时，识别与语音接口返回 503 并给出替代方案，不返回编造结果。”

不要写：

- “AI 识别/语音准确率 xx%”“模型效果已验证”（本机未配置真实服务，未评测）。
- “学生掌握度提升 / 教学效果提升”（无真实试用数据）。
- “记忆曲线/遗忘曲线驱动复习”（当前是经验间隔规则，未做实验校准）。
- “图形与极限结论已证明”（数值探测不是证明）。
