## 一、两轮范围

**2026-09-25（第三阶段）**：数学工具、分层提示、图形批注、语音服务适配、准确性评测、超时降级与错误修正、教师纠错。

**2026-10-10（第四阶段）**：

1. **教学逻辑（刻意练习 / 苏格拉底追问）**：一个知识点固定 4 步（复述条件 → 辨析易错 → 动手算一步 → 迁移自检），
   每步只评价这一步；第 3 步若学生写出显式结果，用本地数学工具核对；作答按长期记忆口径记证据。
2. **知识讲解拆解（树状图）**：章节 → 知识点 → 分支 → 叶子的结构化输出，含人工整理的先修/解锁关系，供 A 端渲染。
3. **集成复核与修正**：核对 A 端对第三阶段接口的接入，修正 `derivative_checked` 字段类型错配（见第五节），

## 五、发现并已修复的问题

1. **主题推断越界**：`求微分方程 y'=y 怎么解`、`概率论里的条件概率` 曾被 BM25 猜成“导数与微分”。
   修复：`suggest_topic()` 增加范围外词表，命中即返回 `null`；加了评测负例。
2. **表达式优先级错误**：解析器曾把 `-x^2` 当作 `(-x)^2`，会让 `exp(-x^2)` 一类函数的求导与绘图结论整体错误。
   修复：按教材语法重排（一元负号低于乘方）；已加回归用例。
3. **图注字段类型错配（10-10 集成复核发现）**：`plot/annotate` 的 `derivative_checked` 返回的是明细对象，
   而 A 端按布尔判断，导致“数值复核未通过”的提示永远不会出现——属于**诚实性缺陷**。
   修复：后端改为返回布尔 `derivative_checked`，明细移到新字段 `derivative_check`；契约、测试、冒烟脚本同步更新。
4. **缺失的接入测试**：`agentTools.ts` 头部声明了 `tests/test_agent_tools.mjs`，但文件并不存在。
   已补 10 项原生 Node 测试（含“后端主题名不在下拉里时不得静默改写主题”这类真实错位）。

以上都是“先用评测/复核把问题暴露出来，再修”，不是事后补写的成绩。

## 六、未评测范围（如实标注）

- **真实模型的语言质量**：未配置 `MODEL_*` 凭据，未评测；本地 72/72 不能替代模型效果。
- **拍照识别（视觉）与语音转写的真实准确率**：需要真实服务与真机音视频，未评测。
- **学习效果**：没有真实师生试用数据，不能声称提升成绩或掌握度。
- **刻意练习的判定口径**：逐步评价 = 关键词覆盖率 + 数值核对，粗糙且可能误判；它不代表掌握。
- **课程资料复核**：12 个知识点与 45 条资源全部 `verified=false`，人工复核后需重跑本评测。
- **数值方法边界**：极限与等价性是取样证据而非证明；多变量、积分、级数不在数学工具支持范围内。
- **A 端界面**：前端逻辑有原生 Node 测试，但未做真实浏览器运行与移动端实机验收。
