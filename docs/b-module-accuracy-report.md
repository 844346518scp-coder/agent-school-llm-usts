# B 模块技术说明与准确性评测报告（2026-09-25）

用途：给项目视频脚本、申报文档与组内评审提供 B（智能体与教学逻辑）的技术说明与可复现的评测数据。
本文只写实测结果；未执行或未具备条件的部分一律标注“未评测”，不得改写为已完成。

## 一、本轮范围

对齐 9 月分工图与 9/25–27 阶段任务，B 本轮的交付是：

1. **数学工具**：表达式解析/求值、符号求导、极限数值探测、等价性校验、零点与极值定位、曲线采样（零第三方依赖）。
2. **分层提示**：概念提示 → 方法提示 → 关键步骤提示，任何层级都不给最终答案。
3. **图形批注**：B 输出步骤、坐标与讲解，A 端负责渲染（对应“圆圈图注”的 B 侧职责）。
4. **语音服务适配**：服务端转写适配、入参校验、口语术语纠错，并提供浏览器原生回退说明。
5. **准确性评测**：7 个套件、62 个用例、逐套件阈值，另有命令行与教师接口两种触发方式。
6. **超时降级与错误修正**：降级码表、只对网络阶段超时重试一次、模型字段白名单修正、内存降级统计。
7. **教师纠错**：教师复核后以追加补偿证据修正判断与掌握状态，原始证据保留。

## 三、评测方法

- 评测集写在代码里（`backend/app/ai/evaluation.py`），每条用例都有“期望值 + 实际值”，失败可复现、可回归。
- 7 个套件与阈值：

| 套件 | 测什么 | 用例数 | 阈值 |
| --- | --- | --- | --- |
| retrieval | 12 道题能否检索到期望知识点（看 top-1） | 12 | 0.90 |
| topic | 主题推断，含“覆盖不足必须返回 `null`”的负例 | 6 | 1.00 |
| diagnosis | 规则诊断命中的首要薄弱知识点 | 3 | 1.00 |
| resources | 资源检索期望条目是否进入 top-3 | 6 | 0.80 |
| math | 求值、符号求导（数值复核）、极限探测（含发散负例） | 18 | 0.95 |
| memory_rules | 掌握度公式、状态阈值、教师纠错权重与钳制 | 10 | 1.00 |
| honesty | demo 不冒充模型、未配置不编造、提示不泄露答案 | 7 | 1.00 |

- 每套件必须分别达到阈值，任一套件未达标即整体不通过。
- 运行环境：本地 SQLite + `AGENT_MODE=demo`（不调用任何外部模型）。

## 五、评测发现并已修复的问题

1. **主题推断越界**：`求微分方程 y'=y 怎么解`、`概率论里的条件概率` 曾被 BM25 得分猜成“导数与微分”。
   修复：`knowledge.suggest_topic()` 增加范围外词表（微分方程、重积分、曲线积分、曲面积分、傅里叶、
   空间解析几何、向量代数、概率论、线性代数、矩阵），命中即返回 `null`；并加入评测负例。
2. **表达式优先级错误**：解析器曾把 `-x^2` 当作 `(-x)^2`（乘方优先级低于一元负号），
   会导致 `exp(-x^2)` 一类函数的求导与绘图结论整体错误。
   修复：按教材语法重排（一元负号低于乘方），`-x^2 = -(x^2)`、`2^-1` 与 `2^3^2` 均正确；已加回归用例。

两处都是“先用评测把问题暴露出来，再修”，不是事后补写的成绩。

## 六、未评测范围（如实标注）

- **真实模型的语言质量**：未配置 `MODEL_*` 凭据，未评测；本地 62/62 不能替代模型效果。
- **拍照识别（视觉）与语音转写的真实准确率**：需要真实服务与真机音频图片，未评测。
- **学习效果**：没有真实师生试用数据，不能声称提升成绩或掌握度。
- **课程资料复核**：12 个知识点与 45 条资源全部 `verified=false`，人工复核后需重跑本评测。
- **数值方法边界**：极限与等价性是取样证据而非证明；多变量、积分、级数不在数学工具支持范围内。

python -m pytest -q

# 准确性评测（7 套件，退出码 0 表示达标；--out 落盘完整 JSON 报告）

python tests/check_agent_accuracy.py --suite math --out tests/_accuracy_report.json
