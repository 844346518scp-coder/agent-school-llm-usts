## 发现的问题

### 1. 双端操作时数据库锁冲突

学生问答保存与教师切换班级统计在相近时间操作后，教师页面显示“暂时无法连接服务”。服务器仍监听，health返回200，但日志有多次 `sqlite3.OperationalError: database is locked`，包括认证读取User路径。手动只读“重新加载”后统计恢复，学生历史中问题仅保存一次。本次没有重试写请求，也没有通过重启掩盖问题。

这是实际隔离页面观察到的稳定性失败；具体锁持有者和机制需结合后续定位，不能仅凭日志断定所有读取都会失败。现有82项通过没有覆盖并保证该交互时序。

追加有界复现：在另一全新合成文件库，经ASGITransport执行8路并发、80次请求（50次列表/统计读取、10次提交、20次演示问答保存），4.704秒全部200/201，无异常或SQL错误，未再次复现。运行配置为SQLite3.50.4、SQLAlchemy2.0.54、journal_mode=delete、busy_timeout=5000ms。当前驱动为legacy事务模式，SELECT后驱动in_transaction=false；认证路径也没有逐请求清理会话，因此没有证据把根因归为“所有读取长期持锁”或“每次认证都删会话”。该探针未覆盖浏览器断连、请求取消或外部进程锁，不能推翻实际页面失败，根因仍未确定。输出位于被忽略的 `.tmp/sqlite-contention-369bcca21d374d16ada6674a84c978a7.json`。

### 2. 知识覆盖与主题错配

内置仅7个知识点、2个主题，全部待课程资料复核；与教师题库12章分类及本次题单没有自动关联。离线调用suggest_topic时，定积分题、级数敛散题均返回“导数与微分”。不能宣称已支持全12章知识点推荐。

脚本执行前禁用并stub dotenv，阻止网络、数据库连接及建表，未导入应用启动模块；防护触发次数为0。报告标记 `NOT_PASSED_KNOWN_ISSUES`，退出0只表示观测报告写入成功。
